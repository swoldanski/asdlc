# aSDLC

Blueprint for projects developed via Agentic SDLC.

This repository is the aSDLC framework template — a highly performant `AGENTS.md` hierarchy that governs how agents work. The root `AGENTS.md` is the binding contract ("aSDLC rail"); `ROADMAP.md` records project direction; `/docs` holds user-facing documentation.

## How to use

- Follow the aSDLC pass on every change: Read Before Editing → edit → Update After Editing → Closeout.
- Keep `ROADMAP.md` current and add user-facing docs under `/docs`.
- The root `AGENTS.md` Child aSDLC Index governs which files are framework-owned vs. project-customized.
- See `AGENTS.md` for the full contract and the Child aSDLC Index for the repository structure.
