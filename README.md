# aSDLC

Blueprint for projects developed via Agentic SDLC.

aSDLC is a highly performant `AGENTS.md` hierarchy that governs how agents
work in this repository. The root `AGENTS.md` is the binding contract (the
"aSDLC rail"); `ROADMAP.md` records project direction; `/docs` holds
user-facing documentation.

## How to use

- Follow the aSDLC pass on every change: Read Before Editing → edit →
  Update After Editing → Closeout.
- Keep `ROADMAP.md` current and add user-facing docs under `/docs`.
- See `AGENTS.md` for the full contract and the Child aSDLC Index for the
  repository structure.
